# Кофеin кофейня — сайт

Одностраничный сайт кофейни «Кофеin» (Москва, ул. Бориса Пастернака, 43).
Статика: чистые HTML + CSS + JS, без фреймворков, без сборщика, без внешних CDN —
загружается мгновенно и хостится где угодно (GitHub Pages, Cloudflare Pages, Netlify, nginx).

## Структура

```
index.html                  — собранный сайт (в git — итог сборки)
templates/index.html        — шаблон с плейсхолдерами {{...}}
assets/css/styles.css       — стили
assets/js/main.js           — мобильное меню и просмотр фотографий
assets/img/photos/          — фотографии (полные + превью)
assets/img/favicon.svg      — фавиконка
data/business.json          — карточка: адрес, часы, телефоны, преимущества
data/menu.json              — меню по разделам с ценами
data/reviews.json           — отзывы гостей
data/photos.json            — манифест фотографий (генерируется)
data/photos-source.csv      — ссылки на фото (источник правды)
data/reviews-photos-source.csv — автор/дата/оценка для фото из отзывов
scripts/build_photos.py     — скачать, отмасштабировать фото, собрать манифест
scripts/build_site.py       — подставить данные в шаблон → index.html
```

## Правки контента

**Цены и разделы меню** — `data/menu.json`, затем:

```bash
python scripts/build_site.py
```

**Отзывы** — `data/reviews.json` (тексты дословные, с Яндекс Карт), затем та же команда.

**Фотографии** — новые ссылки кладутся в `data/photos-source.csv`
(колонки: `#;photo_id;group;source_ru;url_XXXL;url_orig`, `group` ∈ `review|candidate|gallery`),
затем:

```bash
python scripts/build_photos.py   # скачает, ужмёт до 1400/640 px, пересоберёт photos.json
python scripts/build_site.py
```

`build_photos.py` требует Pillow (`pip install pillow`).

## Источники данных (снято 2026-10-22)

- **Меню** — вкладка «Меню» карточки [Яндекс Карт](https://yandex.ru/maps/org/179781002203), 31 позиция в 5 разделах.
- **Фото** — 32 штуки из отзывов (с указанием автора и даты), 19 из подборок тегов карточки, 15 из фотогалереи карточки.
- **Отзывы** — 8 цитат с карточки, дословно.
- **Часы, адрес, телефон, фичи** — карточка Яндекс Карт (халяль, кофе с собой, бизнес-ланч 190 ₽, детское меню, подарочный сертификат, можно с ноутбуком, оплата картой/СБП).

**Перед публикацией нужно подтвердить у владельца кофейни:** актуальные цены, наличие позиций меню,
формулировку про «цветочный магазин рядом» и халяль-формат, а также телефон предзаказа.

## Фотографии и права

Снимки принадлежат авторам отзывов и пользователям карточки. На сайте у каждой фотографии подпись
(«Фото из отзыва <автор>, <дата>») и ссылка на карточку в подвале. Для коммерческого сайта безопаснее
заменить их на собственные снимки кофейни — тогда достаточно положить файлы в `assets/img/photos/`
и поправить `data/photos-source.csv`.

## Публикация

Сайт статический — подойдёт любой хостинг:

1. **GitHub Pages** — `git push` в репозиторий, Settings → Pages → deploy from branch.
2. **Cloudflare Pages / Netlify** — drag & drop папки или подключение репозитория; build command не нужен, output directory — корень.
3. **Свой nginx** — скопировать `index.html` и `assets/` в корень сайта.

После публикации: в `business.yandex.ru` → карточка → «Сайт» указать новый адрес,
чтобы клики из Яндекс Карт вели на него.

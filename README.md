# Кофеin × Flower.For.Rest — сайт кофейни и цветочной студии

Один сайт на два бренда по адресу: Москва, ул. Бориса Пастернака, 43.
Статика: HTML + CSS + JS, без фреймворков и сборщика. Шрифты (Prata, Manrope) — локальные `.woff2`,
внешних CDN нет. Заказы цветов оформляются в WhatsApp/Telegram, оплата — на месте или по счёту.

- Кофейня: `yandex.ru/maps/org/179781002203` — меню, фото, отзывы, кофе с собой.
- Студия: `yandex.ru/maps/org/76375131364` — 159 позиций каталога, доставка, витрина.

## Структура

```
index.html                  — собранный сайт (в git — итог сборки)
templates/index.html        — шаблон с плейсхолдерами {{...}}
assets/css/fonts.css        — @font-face (генерируется fetch_fonts.py)
assets/css/styles.css       — дизайн-система: токены, типографика, компоненты
assets/js/main.js           — шапка, появление секций, меню, каталог цветов, лайтбокс
assets/fonts/               — Prata + Manrope (woff2, подмножества)
assets/img/photos/          — фото кофейни (1400/640 px)
assets/img/flowers/         — фото букетов (1200/560 px)
assets/img/og.jpg           — превью ссылки 1200×630
assets/img/favicon.svg      — фавиконка
data/business.json          — карточка, тексты секций, контакты, id фото
data/menu.json              — меню кофейни
data/reviews.json           — отзывы кофейни
data/photos.json            — манифест фото кофейни (генерируется)
data/photos-source.csv      — ссылки на фото кофейни
data/reviews-photos-source.csv — автор/дата/оценка фото из отзывов
data/flowers.json           — каталог студии: 159 позиций, цены, составы
data/flowers-photos.json    — манифест фото букетов (генерируется)
scripts/fetch_fonts.py      — скачать шрифты и собрать fonts.css
scripts/build_photos.py     — фото кофейни: скачать, ужать, манифест
scripts/build_flowers.py    — каталог и фото студии с Яндекс Карт
scripts/build_og.py         — превью ссылки 1200×630
scripts/build_site.py       — подставить данные в шаблон → index.html
```

## Правки контента

**Тексты, телефоны, шаги, id фото** — `data/business.json`.
**Меню кофейни** — `data/menu.json`. **Отзывы** — `data/reviews.json`.
**Каталог цветов** — `data/flowers.json` (позиции, цены, составы, категории).

После правки данных:

```bash
python scripts/build_site.py
```

**Фото кофейни** — новые ссылки в `data/photos-source.csv`
(`#;photo_id;group;source_ru;url_XXXL;url_orig`, `group` ∈ `review|candidate|gallery`):

```bash
python scripts/build_photos.py
python scripts/build_og.py
python scripts/build_site.py
```

**Каталог и фото студии** (пересобрать с Яндекс Карт):

```bash
python scripts/build_flowers.py
python scripts/build_site.py
```

`build_photos.py`, `build_flowers.py` и `build_og.py` требуют Pillow (`pip install pillow`).

## Заказы цветов

Каждая карточка ведёт в WhatsApp с готовым текстом («Здравствуйте! Хочу заказать: Букет «Воздух», 5 860 ₽»).
Номер и мессенджеры — в `data/business.json` → `flowers`. Корзины и оплаты на сайте нет намеренно:
наличие и состав меняются каждый день, заказ подтверждает флорист.

## Дизайн

- Палитра: тёмно-зелёный `#122a24`, крем `#f8f3ea`, медь `#a96f45`; тёмные секции чередуются со светлыми.
- Типографика: Prata (заголовки) + Manrope (текст), шкала на `clamp()`, метки секций «01 — …».
- Секции: герой, бегущая строка, о кофейне, меню, фото, цветочная студия с каталогом, отзывы, кофе с собой, контакты.
- Каталог: чипы по категориям (букеты/корзины/коробки/ящики/композиции), «показать ещё», карточки на волосяных линиях.
- Доступность: контраст WCAG AA для мелкого текста, фокус-кольца, `prefers-reduced-motion`,
  клавиатурный лайтбокс, alt-тексты с автором фото.

## Фотографии и права

Снимки принадлежат авторам отзывов и пользователям карточек. На сайте у каждой фотографии подпись
(«Фото из отзыва <автор>, <дата>»). Для коммерческого использования безопаснее заменить на собственные
снимки — файлы кладутся в `assets/img/photos/` и `assets/img/flowers/`.

## Публикация

Сайт опубликован на GitHub Pages: <https://dankkoom187.github.io/kofein/>.

1. **GitHub Pages** (текущий вариант) — `git push`, Settings → Pages → ветка `main`, корень.
2. **Свой домен** — GitHub Pages: Settings → Pages → Custom domain + DNS (A-записи GitHub, CNAME для www).
3. **Российский хостинг** — залить `index.html` и `assets/` в `public_html`, включить Let's Encrypt.

После смены домена: вписать адрес в `data/business.json` → `site.url`, пересобрать, задеплоить —
тогда `canonical`, `og:url` и `og:image` станут абсолютными.

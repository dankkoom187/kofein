# Кофеin кофейня — сайт

Одностраничный сайт кофейни «Кофеin» (Москва, ул. Бориса Пастернака, 43).
Статика: HTML + CSS + JS, без фреймворков и сборщика. Шрифты (Prata, Manrope) — локальные `.woff2`,
внешних CDN нет: сайт работает офлайн и грузится одним запросом на страницу.

## Структура

```
index.html                  — собранный сайт (в git — итог сборки)
templates/index.html        — шаблон с плейсхолдерами {{...}}
assets/css/fonts.css        — @font-face (генерируется fetch_fonts.py)
assets/css/styles.css       — дизайн-система: токены, типографика, компоненты
assets/js/main.js           — шапка при скролле, появление секций, меню, лайтбокс
assets/fonts/               — Prata + Manrope (woff2, подмножества)
assets/img/photos/          — фотографии (полные 1400 px + превью 640 px)
assets/img/favicon.svg      — фавиконка
data/business.json          — карточка, тексты секций, телефоны, id фото
data/menu.json              — меню по разделам с ценами
data/reviews.json           — отзывы гостей
data/photos.json            — манифест фотографий (генерируется)
data/photos-source.csv      — ссылки на фото (источник правды)
data/reviews-photos-source.csv — автор/дата/оценка для фото из отзывов
scripts/fetch_fonts.py      — скачать шрифты и собрать fonts.css
scripts/build_photos.py     — скачать, отмасштабировать фото, собрать манифест
scripts/build_site.py       — подставить данные в шаблон → index.html
```

## Локальный запуск

```bash
cd C:\Users\Melchikov_DA\kofein
python -m http.server 8765
# открыть http://127.0.0.1:8765/
```

## Правки контента

**Тексты, телефоны, шаги, подписи, id фото** — `data/business.json`.
**Цены и разделы меню** — `data/menu.json`.
**Отзывы** — `data/reviews.json` (тексты дословные, с Яндекс Карт).

После правки данных:

```bash
python scripts/build_site.py
```

**Фотографии** — новые ссылки в `data/photos-source.csv`
(колонки: `#;photo_id;group;source_ru;url_XXXL;url_orig`, `group` ∈ `review|candidate|gallery`), затем:

```bash
python scripts/build_photos.py   # скачает, ужмёт до 1400/640 px, пересоберёт photos.json
python scripts/build_site.py
```

**Шрифты** (если меняются) — `python scripts/fetch_fonts.py`; нужен Pillow для фото
(`pip install pillow`).

## Дизайн

- Палитра: тёмно-зелёный `#122a24`, крем `#f8f3ea`, медь `#a96f45`; тёмные секции чередуются со светлыми.
- Типографика: Prata (заголовки) + Manrope (текст), шкала на `clamp()`, метки секций «01 — …».
- Секции: full-bleed герой с фактами внизу, бегущая строка, редакционный блок о кофейне с коллажем,
  меню на тёмном с фото, masonry-галерея с подписями при наведении, отзывы с липкой оценкой,
  нумерованные шаги заказа, контакты с картой.
- Доступность: контраст проверен (WCAG AA для мелкого текста), фокус-кольца, `prefers-reduced-motion`,
  клавиатурный лайтбокс (Esc, стрелки), alt-тексты с автором фото.

## Источники данных (снято 2026-10-22)

- **Меню** — вкладка «Меню» карточки [Яндекс Карт](https://yandex.ru/maps/org/179781002203), 31 позиция в 5 разделах.
- **Фото** — 32 из отзывов (с автором и датой), 19 из подборок тегов карточки, 15 из фотогалереи.
- **Отзывы** — 8 цитат с карточки, дословно.
- **Особенности** (халяль, предзаказ, детское меню, ноутбук, сертификаты, бизнес-ланч 190 ₽) — блок
  «Особенности» карточки Яндекс Бизнеса.

**Перед публикацией подтвердить у владельца:** актуальные цены и наличие позиций меню,
особенности из карточки (халяль, ноутбук, цена ланча — атрибуты Яндекса часто устаревают),
формулировку про цветочный магазин и телефон предзаказа.

## Фотографии и права

Снимки принадлежат авторам отзывов и пользователям карточки. На сайте у каждой фотографии подпись
(«Фото из отзыва <автор>, <дата>»). Для коммерческого сайта безопаснее заменить их на собственные
снимки кофейни — файлы кладутся в `assets/img/photos/`, ссылки — в `data/photos-source.csv`.

## Публикация

1. **GitHub Pages** — push в репозиторий, Settings → Pages → deploy from branch.
2. **Cloudflare Pages / Netlify** — drag & drop папки или подключение репозитория; build command не нужен.
3. **Свой nginx** — скопировать `index.html` и `assets/` в корень сайта.

После публикации указать новый адрес в `business.yandex.ru` → карточка → «Сайт».
